Marathon de Paris 2025 — Analyse data des 50 001 finishers
Python · Pipeline de données complet · Google Sheets
⌨️ GitHubPythonrequestspandasGoogle Sheets
Contexte

Le site officiel (results.timeto.com) n'offre aucune API publique. En analysant les requêtes réseau via F12, nous avons identifié une API interne non documentée et construit un pipeline Python complet de bout en bout. Projet réalisé en binôme avec Matthieu Larboullet.

Ce que j'ai fait
  • Collecte : requête GET authentifiée avec simulation navigateur (cookies PHPSESSID + headers user-agent) — récupération de 50 001 entrées
  • Nettoyage : 9 champs utiles extraits parmi ~40 du JSON brut · renommage · 4 variables calculées
  • Enrichissement : search_continent() (code ISO → continent) · runner_cat() (catégorie FFA → sexe, tranche d'âge)
  • Export : JSON + CSV → import Google Sheets pour analyse et visualisation
  • 8 graphiques sur 3 axes : démographie · performance · géographie

TheLook E-Commerce — Profitability & Return Rate Audit
BigQuery SQL · Looker Studio · Fashion Hoodies & Sweatshirts
⌨️ GitHubBigQuerySQLLooker StudioGoogle Cloud
Contexte

Anomalie : malgré une croissance de +154% de CA et +163% de commandes en 14 mois, la rentabilité nette ne progresse pas. Certains segments brassent de l'air — fort volume, marge faible. Les retours érodent silencieusement le P&L.

Ce que j'ai fait
  • Architecture Multi-CTE : 1 CTE par dimension métier (financial_monthly · sessions_monthly · retention_monthly)
  • LEFT JOIN pour garantir l'exhaustivité — aucun article exclu même sans métadonnées
  • SAFE_DIVIDE pour la robustesse en production (NULL vs Division by zero)
  • Marge nette estimée : intègre les coûts logistiques retours (benchmark NRF 16.9%, Zalando 12-15%)
  • 7 requêtes SQL distinctes : retours · genre · variabilité · canal Email · focus Chine · marchés anti-retours

Hackathon Mirakl — Mirakl Connect Prospector
Application web de prospection intelligente · Déployée en 48h sur Vercel
🟢 Déployé⌨️ GitHubNext.jsGPT-4oSupabaseApifyVercel
Contexte

Les BDRs de Mirakl Connect (700+ opérateurs : Carrefour, Leroy Merlin, Best Buy) passaient 1h15 par lead en travail manuel. Ce temps n'était pas consacré à la vente. L'objectif : automatiser le pipeline BDR de bout en bout.

  • Grille de scoring 100 pts : Catégorie (28) · Géographie (22) · Prix (16) · Positionnement (14) · Saisonnalité (10) · Signaux marketplace (10)
  • Outreach personnalisé : méthode × angle × saisonnalité → GPT-4o adapte au profil du seller et à la culture marché
  • Déployé en production sur Vercel avec screenshots réels — pas des mockups
